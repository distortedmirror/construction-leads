# Construction Leads

An Android prototype in Java for connecting construction clients with general contractors, subcontractors, and construction workers.

## Prototype features

- Create a basic profile with role, name, business, specialty, address, location, phone, email, and a short introduction.
- Browse and search sample construction work requests.
- Post a worker request with a title, trade, location, job description, and estimated duration.
- Respond to a request with specialty, contact information, and notes for the client.
- Navigate between a simple home screen, job board, request form, and profile form.

## Run it

Open this repository in Android Studio and allow Gradle sync. Run the `app` configuration on an emulator or Android device (minimum Android 6.0 / API 23).

## Prototype scope

This is a UI and interaction prototype, not a production app. It has no server, user authentication, database, notifications, or real lead delivery. Requests, profile details, and responses are held only in app memory and reset when the process ends. A server/API, secure account handling, and persistent storage will be needed before launch.
